## 2. 各种存储器实际用来做什么

| 存储类别 | 容量 / 当前用量 | 在 FINAL 中的用途 | 断电保持 |
|---|---|---|---|
| 外部 DDR3 主存 | 两颗 4 Gbit ×16，合计 1 GiB；CPU 地址 0x00000000–0x3FFFFFFF | CPU 指令、C 程序数据、BSS、栈；没有将 1 GiB 全部预先占满 | 否 |
| I-Cache 数据 | 16 KiB，2 路、256 组、32 字节行 | 缓存从 DDR3 取出的指令 | 否 |
| I-Cache tag / valid | 两路各 256×20 bit，逻辑容量合计 1,280 B | 记录缓存地址标签和有效状态 | 否 |
| D-Cache 数据 | 16 KiB，2 路、256 组、32 字节行 | 缓存 DDR3 数据，采用写回、写分配 | 否 |
| D-Cache tag / 状态 | 两路各 256×21 bit，逻辑容量合计 1,344 B | 记录地址标签、有效及脏状态 | 否 |
| FPGA DRM 主存 | **0 块** | 原来的 64 KiB DRM 主存已经移除 | — |
| DDR 控制器内部 RAM | **70 个分布式 RAM 资源，0 个 DRM 块** | 读/写路径 FIFO，平滑内部传输 | 否 |
| 总线整行缓冲 / CDC 保持寄存器 | 每份整行数据 32 B，以 FF 实现 | 收集八个 32 位拍、保存请求和响应；不是 CPU 可寻址主存 | 否 |
| 整数寄存器组 | x1–x31 共 31×32 bit = 124 B；x0 固定为零 | CPU 运算状态；报告中寄存器组为 992 个 FF，0 DRM | 否 |
| BTB / 分支预测状态 | 32 项；源码逻辑数组合计 268 B | PC 标签、目标、2 位预测计数器和有效位；以逻辑/FF 实现，0 DRM | 否 |
| 启动程序常量 | demo.bin 680 B，补齐为 704 B / 22 个 32 B 行 | 保存在 FPGA 配置所实现的逻辑常量中，上电复制到 DDR3 并逐行读回校验；0 DRM | 随配置文件重新恢复 |
| 外部 QSPI NOR Flash | XT25BF128F 系列，128 Mbit = 16 MiB；实际烧录占用尚未确认 | 保存 FPGA 配置，供断电后自动启动；当前 CPU 没有直接访问它的程序存储接口 | 是 |
| FPGA 配置 SRAM | 配置容量不以 CPU RAM 资源表统计 | 存放 LUT、布线、IO、RAM 等硬件配置；JTAG 对 FPGA 执行 Program 的目标 | 否 |

**18 块 DRM 的明细：** I-Cache 数据占 8 块、tag 占 1 块；D-Cache 数据占 8 块、tag 占 1 块。合计 16 块数据 + 2 块 tag = 18 块。逻辑数据容量 32 KiB 不等于占用块 RAM 的物理位容量，块粒度和端口配置会产生容量余量。

这里纠正此前概括性描述：当前实际模块报告显示，DDR 控制器没有占用 DRM；18 个 DRM 块全部属于 Cache。DDR 内部缓冲占用的是分布式 RAM。

### DDR3 的“容量”与“占用”

1 GiB 是可寻址主存容量，不表示当前程序占用了 1 GiB。链接脚本仍把当前固件放在 DDR3 的低 64 KiB 软件布局窗口，栈顶为 0x0000FF00；这不限制硬件对完整 1 GiB 的访问。

当前 demo 的 ELF 统计：代码/只读数据 680 B、已初始化可写数据 0 B、BSS 96 B，节大小合计 776 B。装载器写入 704 B（含 24 B 对齐填充），启动代码处理 BSS。栈实际峰值未测量，C 程序还访问六个分散的测试地址，因此不能把 776 B 当作整机 DDR3 运行占用的完整测量值；也没有运行时内存分配/占用统计报告。

### Flash 与比特流占用

当前 `final_top.sbit` 文件为 **2,101,696 B，约 2.004 MiB**。若只按文件长度与 16 MiB Flash 比较，约为 **12.53%**；这是容量参考值，**不是实际烧录占用率**。下载文件转换、Flash 擦除扇区和配置格式可能影响实际写入布局；此前旧闪灯程序、当前工程是否已成功写入 Flash，也没有日志证明。

程序镜像已作为逻辑常量包含在当前 FPGA 配置中，无须再单独烧 demo.hex。Flash 启动成功后，FPGA 先配置硬件，再初始化 DDR3并复制程序。只通过 JTAG 下载到 FPGA 的配置 SRAM，断电后不会保留这次下载。

Flash 型号依据：硬件手册第 2.2.4 节及厂商针对扫描 ID `0x0B4018` 的[说明](https://szlogicmatrix.com/forum-post/724.html)。手册自身列有多种备选型号；此处按此前扫描 ID 对应的芯天下 128 Mbit 系列描述。
